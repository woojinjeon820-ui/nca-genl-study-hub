Where are my records?

이용 안내

처음 쓰기 전에 1분만 읽어 주세요. 특히 기록 저장 방식은 꼭 알아 두세요.

⚠️ 저장 관련 유의 사항

  • 기록(푼 문제, 오답 노트, 메모, 학습 진행, 7일 계획)은 지금 이 컴퓨터의 이 브라우저에만 저장돼요. 서버로 보내지 않아요.
  • 브라우저의 쿠키·사이트 데이터를 지우면 기록도 지워져요. 시크릿(비공개) 창에서는 창을 닫으면 사라져요.
  • 파일을 다른 폴더로 옮기거나 다른 브라우저로 열면 기록이 안 보일 수 있어요. 이럴 땐 백업 파일을 불러오세요.
  • Mac 사파리는 파일로 연 페이지의 저장을 막을 수 있어요. Mac에서도 크롬을 권해요.
  • 화면 위에 노란 경고가 보이면 이 브라우저에서 저장이 안 되는 상태예요. 백업 파일로 저장하세요.

💾 백업하는 법

  • 오답 노트 탭 → 백업 파일로 저장을 누르면 ncagenl-backup-날짜.json이 다운로드돼요.
  • 공부를 마칠 때마다 한 번씩 저장해 두는 걸 권해요.
  • 다른 기기에서 이어서 하려면: 백업 파일을 옮기고 → 그 기기에서 이 HTML을 열고 → 백업 불러오기.
  • 이미 기록이 있으면 합치기(횟수를 더함) 또는 덮어쓰기를 고를 수 있어요.
  • 새 버전 HTML을 받으면 같은 위치에 덮어써서 같은 브라우저로 여세요. 기록이 그대로 이어져요.

📚 권장 사용 방법

  1. 학습: 토픽을 고르고 개념 카드 → 직접 해 보는 도구 → 확인 문제 순서로 진행해요.
  2. 마인드맵: 토픽을 누르면 가지가 펼쳐져요. 하루 공부를 마치고 전체 구조를 훑어보세요.
  3. 문제 풀이: 토픽별로 풀고, 틀린 문제는 자동으로 오답 노트에 들어가요.
  4. 오답 노트: 메모를 남기고 "오답만 다시 풀기"로 반복해요. 연속 2번 맞히면 빠져요.
  5. 모의고사: 시험 전 30문항·30분으로 실전 연습을 해요.
  6. 홈의 7일 계획에 맞춰 하루씩 체크하면 시험 전까지 한 바퀴를 돌 수 있어요.

⌨️ 편리한 기능

  • 오른쪽 위 EN / 한국어로 설명 언어를, 🌙 버튼으로 라이트/다크를 바꿔요.
  • 문제 풀이: 1–4 선택, Enter 정답 확인, ← → 이동.
  • 학습: ← →로 장면을 넘겨요.
  • /를 누르면 전체 검색으로 바로 가요.
  • 실제 시험은 영어라서 문제는 영어 원문으로 두었어요.

How to use this hub

Take a minute to read this first, especially how your records are saved.

⚠️ About saving

  • Your records (answers, notes, memos, learn progress, 7-day plan) are saved only in this browser on this computer. Nothing is sent to a server.
  • Clearing cookies / site data deletes your records. In a private window they vanish when you close it.
  • If you move the file to another folder or open it in another browser, your records may not show. Load your backup file there.
  • Safari on Mac can block saving for local files. Use Chrome on a Mac too.
  • A yellow warning at the top means this browser can't save. Use a backup file.

💾 Backing up

  • Notes tab → Save backup file downloads ncagenl-backup-date.json.
  • Save one at the end of every study session.
  • To continue on another device: move the file → open this HTML there → Load backup.
  • If records already exist you can Merge (adds counts) or Replace.
  • For a new version of this HTML, overwrite the old file in the same place and open it in the same browser. Your records carry over.

📚 Recommended way to study

  1. Learn: pick a topic and go through concept cards → hands-on tools → quick checks.
  2. Mind map: tap a topic to open its branches. Skim the whole structure at the end of each day.
  3. Practice: work topic by topic. Missed questions go to your notes automatically.
  4. Notes: add memos and use "Retry notes only". A question leaves after 2 correct answers in a row.
  5. Mock exam: before the test, do 30 questions in 30 minutes.
  6. Follow the 7-day plan on Home to cover everything once before the exam.

⌨️ Handy features

  • EN / 한국어 at the top right switches language; 🌙 switches light/dark.
  • Practice: 1–4 pick, Enter check, ← → move.
  • Learn: ← → move between scenes.
  • Press / to jump to search.
